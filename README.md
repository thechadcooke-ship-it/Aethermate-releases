# Aethermate — Releases

**Aethermate** is a desktop AI companion who lives on your screen — a
transparent 3D avatar with a wake-word voice, real hands (email, calendar,
docs, browser, MCP tools), a roster of bot mates she can delegate to, and a
local-first privacy posture: your keys, your machine, nothing leaves without
a stamped record.

This is the **public release channel** for the app:

- **Downloads** — grab the latest installer from
  [Releases](https://github.com/thechadcooke-ship-it/Aethermate-releases/releases).
- **Changelog** — see [CHANGELOG.md](CHANGELOG.md).
- **Problems / bug reports** — open an
  [issue](https://github.com/thechadcooke-ship-it/Aethermate-releases/issues/new/choose).
  Reports here feed the support pipeline directly.

- **Open models**: local-first building blocks we use in Aethermate, with honest
  benchmarks, in [`open-models/`](open-models/). The first release is a tuned runtime for
  LFM2.5-VL-3B screen and receipt reading: 90/90 on unseen synthetic images vs 85/90 stock,
  about 3x shorter answers. A fine-tuned Laya decision model comes next.

The application source is developed in a private repository; this repo hosts
releases, release notes, open models, and support intake.
