# Security

Aethermate's application source is developed in a private repository; this repository only hosts releases,
release notes, open models and the support intake.

**Reporting a vulnerability**

- Use GitHub's private reporting: the **Security** tab of this repository, then **Report a vulnerability**.
  Do not put exploit details in a public issue.
- If that option is not available, open an issue titled "security contact request" with no details, and a
  maintainer will arrange a private channel.

Please include the version, what you did, and what you saw. Fixes ship as a new release with a changelog line.
